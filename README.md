# Atividade 4 - Desafio 2

## Cadastro de Produtos com Validação

### Descrição

Este projeto foi desenvolvido em PHP com o objetivo de criar um sistema simples de cadastro de produtos.

O sistema possui um formulário onde o usuário informa o **nome do produto** e o **preço**. Antes de cadastrar, os dados são validados para verificar se estão corretos.

### Funcionalidades

* Cadastro de produtos.
* Validação do nome do produto.
* Validação do preço.
* Verificação se o preço é maior que zero.
* Conexão com banco de dados MySQL.
* Criação da tabela `produtos`.
* Inserção dos produtos no banco de dados.
* Exibição de mensagens de sucesso ou erro.

### Banco de Dados

O projeto utiliza o banco de dados:

```text
exercicio
```

A tabela criada é:

```text
produtos
```

Com os seguintes campos:

* `id`
* `nome`
* `preco`
